SERVICIO 03 · SQL

Base de datos MariaDB

MariaDB almacena datos estructurados en bases de datos y tablas. En el laboratorio se inició el servicio y se ejecutó una consulta para verificar su versión. Para dar contexto al proyecto, se propone usarlo para gestionar los pedidos de un restaurante.

🍽️ Ver caso del restaurante
🗄️

MariaDB Server

Versión comprobada13.0.2ServiciomariadbPuerto habitual3306/tcpPruebaSELECT VERSION()

⚙️ Comandos utilizados

sudo pacman -S mariadb
sudo mariadb-install-db --user=mysql --basedir=/usr --datadir=/var/lib/mysql
sudo systemctl enable --now mariadb
systemctl status mariadb --no-pager
sudo mariadb -e "SELECT VERSION();"

El mensaje de inicialización indicó que la tabla de usuarios ya existía; el servicio arrancó correctamente y devolvió la versión de MariaDB.

🧪 ¿Qué falta para demostrar una base real?

La siguiente práctica recomendada es crear una base de datos de ejemplo, tablas relacionadas y registros de prueba. El caso del restaurante propone clientes, productos, pedidos y detalle de pedidos.

CREATE DATABASE restaurante;
USE restaurante;
SHOW TABLES;

Estos comandos pueden ejecutarse en la consola de MariaDB. La página web informativa no se conecta automáticamente a la base de datos.

Nota técnica: MariaDB se comprobó localmente en el servidor. Para permitir conexiones desde otros equipos habría que configurar autenticación, permisos, bind-address y firewall de forma segura; no es necesario para la demostración actual.
