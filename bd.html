Base de datos MariaDB

MariaDB almacena datos estructurados en bases de datos y tablas. En el laboratorio se inició el servicio y se ejecutó una consulta para verificar su versión. Esta página documenta las pruebas del servicio.

🗄️

MariaDB Server

ServiciomariadbPuerto habitual3306/tcpPruebaSELECT VERSION()

⚙️ Comandos utilizados

sudo systemctl enable --now mariadb
systemctl status mariadb --no-pager
sudo mariadb -e "SELECT VERSION();"

El estado active (running) indica que el servicio está ejecutándose. Ejecuta las consultas desde la laptop del servidor.

🧪 Consultas de comprobación

SHOW DATABASES;
USE laboratorio;
SHOW TABLES;
SELECT * FROM estudiantes LIMIT 10;

La página informativa no se conecta directamente a MariaDB. Las consultas se ejecutan localmente en el servidor.

Nota técnica: MariaDB se comprobó localmente en el servidor. No es necesario habilitar acceso remoto a la base de datos para la demostración.
