SERVICIO 01 · HTTP

Servidor web Apache

Apache recibe solicitudes HTTP y devuelve los archivos de la página web. En este proyecto, el sitio se aloja en CachyOS y se comprobó desde el navegador del celular conectado a la red local.

🔐 Abrir Nube PrivadaVolver al inicio

Nube Privada: http://192.168.100.7:8001/login. Solo funciona en la misma red Wi-Fi mientras la laptop y el servidor estén encendidos.

🌐

Apache HTTP Server

PaqueteapacheServicio systemdhttpdPuerto80/tcpDocumentRoot/srv/http

⚙️ Comandos utilizados

sudo pacman -S apache
sudo systemctl enable --now httpd
systemctl status httpd --no-pager

El estado active (running) indica que el servicio está ejecutándose. Se creó el archivo de inicio en /srv/http/index.html.

🧪 Prueba realizada

Iniciar Apache con systemd.
Crear la página HTML del proyecto.
Abrir http://localhost en la laptop.
Abrir http://192.168.100.7 desde el celular en la misma Wi‑Fi.
Resultado: el navegador del cliente mostró la página alojada en el servidor. Si la dirección IP cambia, hay que consultar ip addr y utilizar la nueva IP.
