SERVICIO 01 · HTTP

Servidor web Apache

Apache recibe solicitudes HTTP y devuelve los archivos de la página web. En este proyecto, el sitio se aloja en CachyOS y se comprobó desde el navegador de un celular conectado a la red local.

🔐 Abrir Nube PrivadaVolver al inicio

Nube Privada requiere que la laptop esté encendida, la aplicación en ejecución y el dispositivo conectado a la misma red Wi‑Fi. Si cambia la IP de la laptop, actualiza el enlace.

🌐

Apache HTTP Server

PaqueteapacheServicio systemdhttpdPuerto80/tcpDocumentRoot/srv/http

⚙️ Comandos utilizados

sudo pacman -S apache
sudo systemctl enable --now httpd
systemctl status httpd --no-pager

El estado active (running) indica que el servicio está ejecutándose. La página del laboratorio está en /srv/http.

🧪 Prueba realizada

Iniciar Apache con systemd.
Abrir http://localhost en la laptop.
Abrir http://192.168.100.7 desde otro dispositivo de la misma Wi‑Fi.
Pulsar «Abrir Nube Privada» para abrir el login de la aplicación local.
Importante: el enlace de Nube Privada usa una IP privada de la red local. No funcionará desde datos móviles ni desde otra red Wi‑Fi. GitHub Pages es una página estática y no ejecuta la aplicación FastAPI.
