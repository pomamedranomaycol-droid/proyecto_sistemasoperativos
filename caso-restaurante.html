Restaurante Sabor Andino

Un restaurante pequeño registra pedidos en papel y a veces pierde información sobre los productos vendidos, las cuentas y los datos de sus clientes. Se propone una base de datos centralizada en MariaDB para organizar los pedidos y facilitar consultas.

🗄️ Volver a MariaDBVer modelo de datos
🍽️

Problema del negocio

Los pedidos se anotan manualmente, cuesta calcular el total de cada mesa y es difícil saber qué productos se venden más.

PropuestaBase de datos relacionalMotorMariaDBBeneficioDatos organizados

Problema y solución

⚠️

Situación actual

  • Pedidos registrados en papel o mensajes dispersos.
  • Errores al sumar el consumo de una mesa.
  • Difícil consultar el historial de pedidos.
  • No hay un reporte rápido de los productos más vendidos.
✅

Solución propuesta

  • Guardar clientes, productos y pedidos en MariaDB.
  • Relacionar cada pedido con sus productos.
  • Calcular el total con consultas SQL.
  • Generar reportes de ventas por fecha o producto.

Ejemplo de implementación SQL

CREATE DATABASE restaurante;
USE restaurante;

CREATE TABLE productos (
  id_producto INT AUTO_INCREMENT PRIMARY KEY,
  nombre VARCHAR(100) NOT NULL,
  precio DECIMAL(8,2) NOT NULL
);

CREATE TABLE pedidos (
  id_pedido INT AUTO_INCREMENT PRIMARY KEY,
  fecha DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
  mesa INT NOT NULL,
  estado VARCHAR(20) NOT NULL DEFAULT 'pendiente'
);

CREATE TABLE detalle_pedido (
  id_detalle INT AUTO_INCREMENT PRIMARY KEY,
  id_pedido INT NOT NULL,
  id_producto INT NOT NULL,
  cantidad INT NOT NULL,
  precio_unitario DECIMAL(8,2) NOT NULL,
  FOREIGN KEY (id_pedido) REFERENCES pedidos(id_pedido),
  FOREIGN KEY (id_producto) REFERENCES productos(id_producto)
);
Importante: este caso es una propuesta académica, no un sistema de restaurante ya desplegado. Antes de usarlo en un negocio real se deben agregar validaciones, copias de seguridad, control de acceso y una aplicación para registrar los pedidos.

Consultas que ayudarían al restaurante

Ver menú

SELECT nombre, precio
FROM productos
ORDER BY nombre;

Consultar pedidos

SELECT id_pedido, fecha, mesa, estado
FROM pedidos
ORDER BY fecha DESC;
