ℹ️ Nota de configuración

Esta página necesita la URL y la clave pública de tu proyecto Supabase. La clave pública se puede usar en el navegador, pero el bucket debe permanecer privado y las políticas de Storage deben limitar el acceso a authenticated.

Por seguridad, no coloques nunca una clave sb_secret_... ni una clave service_role en este HTML.
