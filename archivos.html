SERVICIO 02 · SMB

Servidor de archivos Samba

Samba permite compartir una carpeta entre dispositivos. Se configuró el recurso Compartido y se comprobó que el celular podía entrar mediante X-plore usando credenciales de usuario.

📁

Recurso Compartido

Ruta local/srv/samba/compartidoProtocoloSMBPuerto445/tcpClienteX-plore / Android

⚙️ Instalación y validación

sudo pacman -S samba
sudo testparm
sudo systemctl enable --now smb
systemctl status smb --no-pager
smbclient -L localhost -N

El recurso Compartido apareció en la lista de recursos compartidos. Se habilitó el acceso SMB en el firewall desde la subred local.

👥 Gestión de usuarios

Se configuraron usuarios Samba para que los clientes se autentiquen con una cuenta individual en lugar de depender del acceso anónimo.

sudo smbpasswd -a NOMBRE_USUARIO
sudo testparm
sudo systemctl restart smb

En la configuración del recurso, valid users debe incluir los usuarios autorizados. Los permisos de Samba y los permisos del sistema de archivos deben permitir la operación solicitada.

Prueba desde Android

1️⃣

Conectar a la red

El celular y el servidor deben estar en la misma Wi‑Fi o tener una ruta de red permitida.

2️⃣

Agregar servidor

En X-plore se usó la IP del servidor, el recurso Compartido y las credenciales de Samba.

3️⃣

Leer y guardar

Se comprobó el acceso al recurso. La escritura depende de que los permisos de Linux y Samba coincidan.

Seguridad: el puerto SMB debe limitarse a la red local. No publiques el puerto 445 en Internet ni compartas contraseñas entre usuarios.
