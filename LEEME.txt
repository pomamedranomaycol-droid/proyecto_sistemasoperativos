PROYECTO CACHYOS - WEB ACTUALIZADA

Cambios:
- Se quitó el enlace y el archivo "caso-restaurante.html".
- Se conservó el diseño general oscuro y las páginas del proyecto.
- Se actualizó archivos.html con una interfaz para iniciar sesión, subir, listar, descargar y eliminar archivos mediante Supabase Storage.
- La integración aún requiere pegar la Project URL y la clave pública de Supabase en archivos.html.

Antes de usar:
1. Abre archivos.html en GitHub y pulsa Edit.
2. Busca las constantes SUPABASE_URL y SUPABASE_PUBLISHABLE_KEY.
3. Sustituye PEGA_AQUI_TU_PROJECT_URL por la URL del proyecto.
4. Sustituye PEGA_AQUI_TU_SB_PUBLISHABLE_KEY por la clave sb_publishable_...
5. Guarda con Commit changes y espera a que GitHub Pages publique.

Seguridad:
- Nunca coloques sb_secret_... ni service_role en HTML.
- Bucket debe permanecer privado.
- Las políticas SELECT/INSERT/DELETE deben aplicarse a authenticated y restringir bucket_id = 'archivos-compartidos'.
- Esta interfaz inicia sesión con correo y contraseña (Supabase Auth), no con un nombre de usuario aislado.
- El código permite que usuarios autenticados eliminen cualquier archivo del bucket, si así lo permiten las políticas. Usa con cuidado.
