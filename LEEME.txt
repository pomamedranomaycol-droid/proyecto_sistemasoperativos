ACTUALIZACIÓN SEGURA — PROYECTO SISTEMAS OPERATIVOS

Este ZIP contiene dos archivos HTML actualizados:
- web.html: cambia el botón "Abrir servidor local" por "Abrir Nube Privada" y apunta a http://192.168.100.7:8001/login.
- bd.html: elimina el botón "Ver caso del restaurante".

IMPORTANTE:
Este paquete NO incluye el resto del sitio porque archivos.html contiene la configuración existente del portal de archivos/Supabase y no debe reemplazarse por una reconstrucción que pudiera perder esa integración.

Cómo aplicarlo:
1. Descarga y descomprime este ZIP.
2. En GitHub abre el repositorio proyecto_sistemasoperativos.
3. Reemplaza únicamente web.html y bd.html por los archivos de este paquete.
4. Haz Commit changes para ambos archivos.
5. Espera a que GitHub Pages publique los cambios y recarga la web.

El enlace http://192.168.100.7:8001/login funciona solo desde la misma red local, si la IP sigue siendo 192.168.100.7 y Nube Privada está ejecutándose. No funciona desde otras redes ni datos móviles.
