Implementación de servicios de red en un servidor Linux

Un laboratorio práctico con CachyOS que integra un servidor web, un servicio para compartir archivos y un gestor de base de datos. El objetivo es aprender a instalar, configurar, probar y documentar servicios reales.

🎯 Objetivos del proyecto

  • Instalar y administrar servicios de red en Linux.
  • Permitir que un dispositivo cliente acceda a servicios del servidor.
  • Configurar autenticación para compartir archivos.
  • Probar MariaDB y explicar un uso real de una base de datos.
  • Documentar comandos, resultados y posibles mejoras.

🧭 Arquitectura del laboratorio

La laptop con CachyOS cumple el rol de servidor. El celular conectado a la misma Wi‑Fi actúa como cliente para abrir la página web y acceder a la carpeta SMB.

Celular / cliente
       │ Wi‑Fi / LAN
       ▼
Laptop CachyOS — 192.168.100.7
  ├─ Apache  : 80/tcp
  ├─ Samba   : 445/tcp
  └─ MariaDB : 3306/tcp (local)

Nota: no se ha habilitado MariaDB para acceso remoto; la base de datos se comprobó desde el servidor.
